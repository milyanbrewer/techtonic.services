# techtonic.services

Kaltura Embed Lab: a single-page tool for building Kaltura `embedPlaykitJs` iframe URLs from the [playkit-js](https://github.com/kaltura/playkit-js) config options.

- Live: https://techtonic.services (GitHub Pages, `CNAME` file)
- Local: `docker compose up -d --build`, then http://localhost:8088
